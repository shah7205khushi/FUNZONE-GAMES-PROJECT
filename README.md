# 🎮 FunZone Game

FunZone Game is a collection of interactive browser-based games developed using **HTML, CSS, and JavaScript**. The project includes three classic games—**Flappy Bird**, **Memory Game**, and **Block Puzzle**—designed to provide an engaging gaming experience while demonstrating core web development and JavaScript programming concepts.

---

## 📌 Project Overview

The objective of this project is to create an entertaining web-based gaming platform where users can enjoy multiple games without installing any software. Each game is built using JavaScript logic and HTML5 Canvas, offering smooth gameplay and responsive interactions.

---

## ✨ Features

- 🎮 Three interactive games in one platform
- 🐦 Flappy Bird game with score tracking
- 🧠 Memory Card Matching Game with Easy and Hard modes
- 🧩 Block Puzzle Game
- 📱 Responsive user interface
- ⚡ Smooth animations using HTML5 Canvas
- 🏆 Real-time score tracking
- 💻 Browser-based gameplay (No installation required)

## 🎮 Gameplay Features

### Flappy Bird
- Bird movement using keyboard controls
- Collision detection
- Dynamic obstacle generation
- Score system

### How to play Game ?

- Press the start  button to start the game 
- Press the space bar  key ,upper key ,and  X key to fly the bird
- The bird  automatically falls down
- Control the bird through the pipes with random heights
- Fly as far as possible to get high scores
- The game will over when the bird hits one of the tubes , ground, or ceiling
- Press restart button to play game again


### Memory Game
- Flip cards to find matching pairs
- Timer functionality
- Easy and Hard modes
- Win message after completing all matches

### how to play Memory game?

- Players need to find pairs of matching cards .
- Three levels of this game easy , medium , hard.
- Player will click on two card one by one.  
- If two card are matched they will be kept open otherwise both card close.  
- when player completes the level .the time and moves will be displayed on screen .  
- When two cards will be open then show moves 1 .  
- The winning message will be  displayed .  
- There is a option to go to next level or go to main page.  


### Block Puzzle
- Smooth block rendering
- Continuous game loop
- Collision handling
- Score tracking
